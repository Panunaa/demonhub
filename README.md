# Demonhub

The hardest Geometry Dash demons, ranked. Live placements, points and records from [demonlist.org](https://demonlist.org) and [AREDL](https://aredl.net).

**Play:** https://panunaa.github.io/demonhub/

- `index.html` — весь сайт (список, профиль уровня, лидерборд, аккаунты)
- `data.json` — снимок списка; обновляется ботом ежедневно (`scripts/update_data.py`)
- живые данные тянутся с API при каждом открытии; снимок — запаска, если API недоступен
